Studio IA gratuit

Obtenir une clé gratuite

Plan d’amélioration

Objectif : une interface de type Claude qui utilise les modèles IA gratuits sans clé et sans erreur. Une clé ne peut pas être créée sans votre accord : le plan vise donc soit aucune clé (Puter), soit une clé générée en un clic (connexion OpenRouter). Touchez l’état d’une tâche pour le changer, choisissez une date, ou générez le code.
